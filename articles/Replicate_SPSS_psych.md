# Replicate SPSS and R psych results with EFAtools

This vignette demonstrates the replication of exploratory factor
analysis (EFA) results (specifically, principal axis factoring \[PAF\]
with subsequent promax rotation) from the SPSS `FACTOR` algorithm and
from the [`fa()`](https://rdrr.io/pkg/psych/man/fa.html) function from
the `psych` R package. For a general introduction to the `EFAtools`
package, please see the
[**EFAtools**](https://mdsteiner.github.io/EFAtools/articles/EFAtools.md "EFAtools")
vignette. Same as in the EFAtools vignette, we will use the DOSPERT data
set for this demonstration as well (see
[`?DOSPERT`](https://mdsteiner.github.io/EFAtools/reference/DOSPERT.md)
for details).

First load the needed packages EFAtools and psych (original SPSS results
for some data sets are available in the EFAtools package).

``` r

library(psych)
library(EFAtools)
#> 
#> Attaching package: 'EFAtools'
#> The following object is masked from 'package:psych':
#> 
#>     KMO
```

## Principal Axis Factoring

First, we will fit an EFA with PAF and without rotation using the
`efa_fit` function from `EFAtools`, supplying the `"psych"` and `"SPSS"`
presets through
[`estimate_control()`](https://mdsteiner.github.io/EFAtools/reference/estimate_control.md)
and
[`rotate_control()`](https://mdsteiner.github.io/EFAtools/reference/estimate_control.md).
These presets are intended to mimic the R psych and SPSS results,
respectively.

``` r

# EFAtools::efa_fit with the psych preset, without rotation
EFA_psych_paf <- efa_fit(DOSPERT$cormat, n_factors = 10, N = DOSPERT$N,
                         estimate_control = estimate_control(type = "psych"),
                         rotate_control = rotate_control(type = "psych"))
# EFAtools::efa_fit with the SPSS preset, without rotation
EFA_SPSS_paf <- efa_fit(DOSPERT$cormat, n_factors = 10, N = DOSPERT$N,
                        estimate_control = estimate_control(type = "SPSS"),
                        rotate_control = rotate_control(type = "SPSS"))
```

As a next step, we fit an EFA with the same configurations (PAF and no
rotation) using the `fa` function from `psych` with the same data set.

``` r

# psych::fa without rotation
psych_paf <- psych::fa(DOSPERT$cormat, nfactors = 10, n.obs = DOSPERT$N,
                       fm = "pa", rotate = "none")
```

Now we can compare results from `efa_fit` with the respective presets to
the original R `psych` and `SPSS` results using the same data set. This
is easily done using the `efa_compare` function available in the
`EFAtools` package.
